NILOMONI QA PORTFOLIO WEBSITE DEMO

HOW TO VIEW
1. Extract the ZIP file.
2. Open index.html in Chrome, Edge, Firefox or Safari.
3. Internet is needed for Google Fonts. The website itself runs locally.

FILES
- index.html: website structure and portfolio content
- styles.css: responsive visual design, layout and animations
- script.js: typing effect, scroll reveals, counters, mobile menu,
  interactive demo pipeline and animated particle background

NOTES
- This is a front-end portfolio demo, not a deployed public website.
- The EMPWR dashboard is an illustrative mock-up, not a screenshot or live data.
- The Playwright pipeline button animates a demonstration only; it does not run tests.
- Contact and LinkedIn links point to the details supplied in the CV.
- Review all wording and contact details before publishing.
